# Briefs

Design briefs for Claude Design, one `UPPERCASE.md` file per screen or flow,
written before a plan that adds or reshapes a screen is approved
(`~/AGENTS.md`, "Planning UI work"). Each one opens with this repository's
link (https://github.com/masshirodev/ranma, public) and the files the designer should read, and
ends by asking the designer to mark the design finished.

A brief whose handoff has been implemented moves to `done/`.
