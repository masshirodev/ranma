# The picker, redrawn (card c302), cell for cell.
# Help, the command palette, the switchers, plugin pickers, prompts and
# questions: one drawing with variations. Looks only: keys and matching do not
# change. Laid out by mock.py from the rules below, so the two agree; the
# rendered version is the "Picker, redrawn" Design canvas (dark and light).
#
# HOW TO READ
#   Each state is the whole screen ("## WxH · state · border.style"), then its
#   role mask ("### roles"): the same block, one letter per cell.
#     b picker_border      f picker_fg          F picker_fg, bold
#     d picker_dim         a picker_accent      A picker_accent, bold
#     e picker_error, bold m picker_match (later step)
#     C the terminal's cursor (█ in the block)
#     space  a blank cell on the box's ground
#     .      not the picker: panes and bar, drawn as today
#   Ground: every cell of the box, border included, is picker_bg; a selected
#   row's inner cells are picker_cursor_bg (the mask line says so at its end).
#
# ANATOMY (top to bottom)
#   border + title     ╭─ projects ───╮     title in picker_fg bold, from cell 3
#   query row          │ › ra█   9/48 │     prompt glyph, query, count
#   rule               ├──────────────┤     picker_border, the border's own joints
#   list rows          │▌ ● ranma  ~/ │     bar, mark, label, detail
#   border + footer    ╰── ^R rename ─╯     the picker's own keys, right
#
# ROLES. Every new role is optional and follows an existing one, so every theme
# written so far (matugen's included) draws the new picker without an edit.
#   role               used for                                   unset, follows
#   picker_fg          labels, the query, a question's message    toast_fg
#   picker_bg          the box's ground, border included          toast_bg
#   picker_border      border, the rule under the query           bar_dim
#   picker_dim         details, count, placeholder, footer words  bar_dim
#   picker_accent      prompt glyph, ▌, ●, +, run, active mode,   picker_selected_bg
#                      the scroll thumb
#   picker_cursor_bg   the selected row's ground                  picker_selected_bg mixed
#                                                                 22% into picker_bg, in
#                                                                 real RGB (as dim_unfocused
#                                                                 mixes); border_inactive when
#                                                                 either cannot be resolved
#   picker_error       the palette's error row                    bar_urgent
#   picker_match       matched letters (later step)               picker_accent
#   No longer drawn by the list: picker_selected_fg (dark text meant for a
#   saturated slab). It stays for the touch sheet and the settings panel, and
#   picker_selected_bg lives on as the accent's and the cursor's source, so a
#   theme's chosen selection colour still marks the picker, in small doses.
#   The border stops being mode_bg: the WM-mode colour on a box that is not WM
#   mode competed with the selection. It follows bar_dim, not border_inactive:
#   dark themes set border_inactive a step off the ground (sumi: 1.2:1 on
#   toast_bg), which would lose the rule under the query.
# STYLES ([styles], attributes per role)
#   picker_selected  the selected row's label         default ["bold"] (was [])
#   picker_title     the title                        default ["bold"]
#   picker_query     the typed text                   default ["bold"]
#   picker_current   the ● of where you are           default []
#   picker_error     the error row                    default ["bold"]
#   picker_match     matched letters (later step)     default []
#
# DECISIONS
#   Selection. ▌ in picker_accent in the first inner cell, the row on
#   picker_cursor_bg, the label bold. No full-saturation slab: the tint is the
#   theme's own selection colour at 22%, so the selected row is the clearest
#   thing in the box without being the loudest thing on the screen.
#   Current. ● in picker_accent in the mark column, label not bold (bold is the
#   selection's now). Selected and current: both, ▌ and ●. The mark column
#   exists when any item at open is current, so typing never shifts columns.
#   Query row. Prompt glyph (› in picker_accent, bold), the query in picker_fg
#   bold, the cursor, a dim placeholder when empty, the count right in
#   picker_dim (matches/all). Under it a rule in picker_border with the border's
#   joints (├ ┤), as the settings panel has it. In the palette the glyph is the
#   typed prefix (? or :) and the title shows both modes, the active one in
#   picker_accent bold, the other dim: `? keys   : commands`.
#   Columns. Label first, picker_fg. Detail in picker_dim, left-aligned in a
#   column after the widest label (+3 cells), not pushed to the right edge: it
#   reads as a table and a long path no longer pulls the eye. Cut order when
#   the box is narrow: the detail (from the middle when it has a `/`, at its
#   end otherwise), then, under 8 cells, the detail goes; the label is cut
#   last, at its end. A detail ending in `/<label>` drops that ending
#   (`~/projects/agents.ranma` beside `agents.ranma` is `~/projects/`).
#   Variations of the row (one component):
#     column  label, detail column                 switchers, plugins, servers
#     key     label (name dim argument hint),      the command palette, menus
#             key right-aligned, dim
#     help    key right-aligned against the action (leader dim, chord bold, as
#             the which-key hint), the action, `global` as the detail
#   Special rows: `run` (accent bold) + the line (bold); `! error` in
#   picker_error; `+` (accent) in the mark column + the new name as the label
#   + `new session`/`new workspace` as the detail; `nothing matches` (dim).
#   Position in a long list. A thumb on the right border over the list rows,
#   as panes.scrollbar: ┃ in picker_accent (# with ascii). On
#   thick and double borders the glyph is the border's own weight, so the
#   colour carries it. No `↓ 40 more` rows: they cost rows and repeat the count.
#   Size. Width from the widest label and detail of every item at open:
#   lead (2, +2 with a mark column) + label + 3 + detail + 1, plus the borders,
#   then clamped to 44..88 and never more than the screen less 4. At least the
#   title's and the footer's width. Height: list rows = items at open (+1 for
#   pickers that can offer a new item), at most 16 and at most two thirds of
#   the screen less 4, at least 1; box = rows + 4. Both are fixed at open:
#   typing never resizes the box, it leaves blank rows.
#   Position. Centred across, a third of the way down: y = (rows - h) / 3,
#   as today.
#   Footer. On the bottom border, right, `key word · key word · esc`, keys in
#   picker_fg bold, words and dots dim; only on pickers with keys you could
#   not guess:
#     sessions, move workspace   ^R rename · esc
#     servers                    ↵ move here · ^X kill · esc
#     help (? keys)              ↵ runs it · esc
#     commands (: …)             tab completes · ↵ runs · esc
#     prompts                    ↵ <verb> · esc  (+ `empty clears` where it does)
#     questions                  the answer keys: y quits · any other key stays
#     plain switchers, plugins   none
#   The parenthesised hints in today's titles and messages move here, so
#   titles become nouns (`servers`, `rename session main`).
#   Prompt. Three rows, the query row only; width max(40, title) + 4, at
#   least 30. Question. Three rows, the message in picker_fg bold from the
#   second cell, no glyph, no cursor.
#   Border styles. border.style, as today, and its joints for the rule
#   (custom: ├ ┤ from the light set when its chars are light, + when not).
#   ascii: ▌ → `>`, ● → `*`, thumb `#`, joints `+`. none keeps today's
#   fallback, rounded: a box over panes needs an edge.
#   Narrow (under ~44 columns). The box is the screen less 4. In order, what
#   goes: the inactive mode in the title, the footer when it does not fit, the
#   detail (under 8 cells), the help leader (the same on every row), the
#   count when the query needs the room. The label is cut last.
#   Touch sheet. Unchanged: big button faces and the full picker_selected
#   slab are right for a thumb. Nothing here contradicts it; the sheet's
#   `type to filter` is the same placeholder.
#   Later steps, not this change: matched letters in picker_match (fuzzy_score
#   returning positions), and a preview panel beside the list for the pane and
#   layout switchers when the screen is 160+ wide (last mock).
