ranma packages

Release builds of ranma, a tiling window manager for the terminal, for Linux with glibc 2.34 or newer, on x86_64 and aarch64. Every channel ships the same binary.

Any distro

curl -fsSL https://masshirodev.github.io/ranma/install.sh | sh

Debian, Ubuntu

sudo install -d /etc/apt/keyrings
curl -fsSL https://masshirodev.github.io/ranma/ranma.asc | sudo tee /etc/apt/keyrings/ranma.asc >/dev/null
echo "deb [signed-by=/etc/apt/keyrings/ranma.asc] https://masshirodev.github.io/ranma/deb stable main" | sudo tee /etc/apt/sources.list.d/ranma.list
sudo apt update && sudo apt install ranma

Fedora, RHEL, openSUSE

sudo curl -fsSL -o /etc/yum.repos.d/ranma.repo https://masshirodev.github.io/ranma/ranma.repo
sudo dnf install ranma

openSUSE: sudo zypper addrepo https://masshirodev.github.io/ranma/ranma.repo && sudo zypper install ranma

Arch, Nix, cargo, npm

See the README's Install section.
